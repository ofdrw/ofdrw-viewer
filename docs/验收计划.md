# OFD 渲染引擎 v1 验收计划（T8b + R1 密码能力扩展）

> 依据：《OFD 渲染引擎设计方案》v0.5-r12 第 19.4/19.6/15/18/3 节、`docs/CONTRACTS.md`、
> `docs/测试方案.md`（T8 harness 口径与第 11 节 R1 密码测试矩阵）。
> 执行者：T11 独立验收（engine 原范围）；R1 密码能力由各独立验证任务执行，t34 V-FINAL
> 对当前字节做 consolidated 复验；t23 统一写 `docs/验收报告.md`。
> 本计划只描述“怎么验、用什么证据判定”，不替代实现与回归报告。
> 版本：T8b + R1/T55；最后更新：T55（第 14 节密码能力验收、退出码、浏览器/SEA、无障碍与 stale 策略）。

## 1. 目的与使用方式

把 19.6 的 18 条验收清单和 Web/性能/安全/取消/close 补充项，逐条映射为：

```text
验收项 → 方法/断言 → 可执行命令 → 样本/fixture → 期望 → 证据路径 → 通过标准 → 失败复现
```

T11 按第 11 节顺序执行 engine 验收，把每条结论（pass/fail/blocked + 证据）提交给 t23 汇总写入
`docs/验收报告.md`。**19.6 的 18 条全部为发布门禁**；补充项中 P/S/Z/W 为门禁，M 为人工门禁，
未通过不得给出“通过”结论。

R1 密码能力（engine 虚拟容器、crypto、UI、CLI）按第 14 节验收；其发布门禁与 engine 同等，
最终以 t34 V-FINAL 对当前 workspace 的 consolidated 结果为准。t23 负责汇总报告，本计划不写报告。

约定：

- pass 必须有命令退出码 + 证据文件，不接受“人工看了一眼”作为唯一证据；
- 失败必须记录样本/页、期望 vs 实际、复现命令、建议 owner；
- 任何一条 19.6 无法执行（缺 harness/样本/服务）按 **blocked → 不通过** 处理，不得跳过；
- 本计划的口径变更由 QA 更新并通知 captain，T11 只追加结果。

## 2. 验收范围

### 2.1 范围内

- 平台无关引擎核心：容器/XML/模型/资源/样式/字体/文字/图片/渲染/渲染器/API；
- H5 Canvas2D 默认渲染器（浏览器 + Node `@napi-rs/canvas` 注入）；
- Node canvas 黄金图与 55 对真实 OFD/PDF 回归（manual 本地可选；dense-text-perf 已提供）；
- `examples/web` 最小验证页（File/Blob/URL、dpi、多页、warning、字体注入、取消）；
- 包导出（ESM/CJS/types）、构建、性能/稳定性/安全/取消/close；
- **R1 密码能力**：engine `VirtualContainer` 注入/生命周期/明文；`@ofdrw/ofdrw-viewer-crypto`
  SM/ASN.1/证书/解密/签章/完整性/时间戳；UI 加密打开/验证面板/印章/根证书/适配层/无障碍；
  CLI `info`/`verify`/加密转图片/退出码/SEA；统一 Java/oracle 夹具与浏览器验证（第 14 节）。

### 2.2 范围外（明确不验收）

- Node/微信/小程序真机适配器；Electron/跨浏览器矩阵（设计 19.4 明确由宿主自测）；
- 注释编辑 UI；完整阅读器交互；与 PDF 逐像素一致（PDF 仅作版式/位置参考，设计 19.2）；
- 业务原件入库：`ofd_pdf_match/` 现有文件只读，manual 不提交；
- 原 T8b 的“签名密码学验证”排除项已被 R1 扩展取代：签名/完整性/时间戳解析纳入第 14 节，
  但**不验证 TSA 签名**（时间戳只解析，状态固定 `parsed-not-verified`）；
- 不验证吊销（CRL/OCSP），`revocation=not-checked`；不提供独立 `decrypt` 命令。

## 4. 证据规范

### 4.1 目录

所有证据写入（不提交，除非 captain 指定）：

```text
test/acceptance/artifacts/<run-id>/
  environment.txt          # node/pnpm/poppler/浏览器版本、CPU/内存、git 状态
  commands.log             # 时间、命令、退出码、耗时
  summary.json             # 机器汇总：19.6/P/S/Z/W 的结论
  19.6/A01/ ... A18/       # 每项日志/JSON/截图（按需）
  perf/P1-open-1000.json ...
  stability/S1-500pages.json ...
  security/Z1-zip-bomb.log ...
  web/W1-hello.png ...
  manual-review.md         # M1–M9 人工判断记录（截图引用）
  golden-report.sha256     # 引用 test/.artifacts/golden/<ts>/report.json 的哈希
```

`run-id = YYYYMMDD-HHmmss`（本地时间）。截图命名 `W<编号>-<样本>-<状态>.png`，1440×900。

### 4.2 记录规则

- 每条命令追加到 `commands.log`：`<ISO时间> <退出码> <耗时ms> <命令>`；
- 大产物（黄金图 pages、PDF）不复制，记录源路径 + `sha256sum`；只复制 `report.json` 摘要/截图；
- 性能数据记录 5 次原始值 + 中位数，不只写结论；
- 截图必须能看出页面内容（非空白）、页码、warning/error 面板（若有）；
- 证据中不写业务敏感信息全文；warning 只记录 code/消息/ID。

### 4.3 清理

执行结束后：

1. `playwright-cli close`；`playwright-cli list` 确认无会话；必要时 `playwright-cli close-all`；
2. 停止 `examples/web` dev/preview 与临时 fixture 服务（kill PID）；`ss -ltn` 确认 5178/5179 已释放；
3. 删除 `.playwright-cli/` 下的临时 snapshot/video/trace（保留已复制到证据目录的截图）；
4. 删除 `test/.fixtures/acceptance/`、临时 CORS 服务文件等；`test/.artifacts` 与 `test/acceptance/artifacts` 保留供复核；
5. 不删除 `docs/回归报告.md` 引用的产物；不 `git push`。

### 5.1 关键判定细则

- **A01 的“不整包解压”**：以读取条目名为准，不以耗时为准。读取 `Pages/*/Content.xml` 任一即 fail；
  只读 `OFD.xml`/`Document.xml` 且 open<100ms 才 pass。
- **A02**：`fillText` 等只允许出现在注释/文档字符串；运行时用 `RecordingRenderer` 或 Proxy 统计调用次数。
- **A03**：内嵌字体样本若本身含缺字，可接受 `W_GLYPH_MISSING`，但必须列明字形 ID/字符，不得整页空白。
- **A04**：无补充字体时“不崩溃 + warning”即满足该项；有补充字体时必须能读到文字（ink>0 且与无补充有差异）。
- **A06**：先执行 G5 注入检查。`test/golden/lib/engine.ts` 没有 `imageDecoders` 时禁止判 pass；
  PNG/JPEG 由 `nodeImageDecoders`，JBIG2/TIFF 由 T5b 插件，不得在 harness 重复实现。
- **A11**：`Visible=false` 用合成 fixture 断言像素不出现；`NoZoom/NoRotate` 用“同一 Appearance 开/关”两张 PNG
  逐像素比较（允许 0 差异；若实现选择忽略属性，内容必须完全一致）。
- **A14/A15**：warning 必须由 `onWarning` 捕获并记录 code；仅日志打印不算通过。
- **A16**：基线目录只允许人工审核后更新；T11 不提供自动 `--update`。黄金图通过指
  `run-all` summary 0 失败，不代表“与人工基线完全一致”（基线缺失不算失败，见测试方案）。
- **A17**：types 检查用临时 consumer（`test/acceptance/consumer-types.ts` + 临时 tsconfig），
  不修改包源码/根 tsconfig。
- **A18**：close during render 的 rejection code 接受 `OFD_ABORTED` 或 `OFD_CLOSED`（设计 16.2 允许先置 closed 再中止），
  但必须二选一且不 hang；`cancel()` 必须是 `OFD_ABORTED`。

### 6.4 非空白/尺寸测量（可在 `eval` 中执行）

```js
// playwright-cli --raw eval "..." 读取主 canvas 的尺寸与非白像素比例
(() => {
  const c = document.querySelector('canvas');
  if (!c) return { error: 'no canvas' };
  const d = c.getContext('2d').getImageData(0, 0, c.width, c.height).data;
  let ink = 0;
  for (let i = 0; i < d.length; i += 4) {
    if (d[i] < 245 || d[i + 1] < 245 || d[i + 2] < 245) ink++;
  }
  return { width: c.width, height: c.height, inkRatio: ink / (c.width * c.height) };
})()
```

- `inkRatio > 0.002` 视为非空白（文字页通常更高）；空白页/缺字体页 W5 允许低 ink，但必须不崩且有 warning。
- canvas 尺寸与 `page.getViewport({dpi})` 的偏差 ≤1px；144/300 同理。

### 14.4 CLI 退出码验收

| 退出码 | 语义 | 必测场景 | 证据 |
| ---: | --- | --- | --- |
| 0 | 成功 | 转图片全成功；`info`（含加密包无凭据）；`verify overall=valid` | stdout/产物 + exitCode |
| 1 | 用法/参数/路径 | 未知参数/子命令、缺输入、`info` 带凭据/根、`decrypt`、凭据冲突、页码越界 | stderr 用法提示 + exitCode |
| 2 | 文档级失败 | 非 OFD、包损坏、必需部件缺失、解密前结构错误 | 错误码 + exitCode |
| 3 | 页级失败 | 至少一页失败、至少一页成功 | 已产页清单 + exitCode |
| 4 | 加密/凭据失败 | 缺凭据、用户不存在、口令/私钥错误、解密失败、不支持加密 | 无页产物 + exitCode |
| 5 | 验证未通过 | `verify` invalid/unknown/unsupported/not-applicable；篡改/夹带/错根 | 报告 overall + exitCode |
| 130 | 用户中断 | SIGINT/AbortSignal | 进程退出码 130；无残留 |

`info` 不得因加密包无凭据失败；`verify` 的 `unknown` 是合法“未配置根”结果，必须 5；不得把
“未配置根”误判为失败或 0。

最小黑盒样例（`$FIX` 指统一夹具目录；凭据见 `docs/测试方案.md` 11.3）：

```bash
FIXTURE_PASSWORD='FixturePass123'   # 测试夹具口令，仅 test-only
ofdrw-viewer-cli info "$FIX/password-encrypted.ofd" --json          # 0，仅查询
ofdrw-viewer-cli verify "$FIX/signed-sesv4.ofd" \
  --root "$FIX/certs/root-ca.crt.pem" --json                         # 有效→0
ofdrw-viewer-cli verify "$FIX/signed-sesv4.ofd" --json               # 无根 unknown→5
ofdrw-viewer-cli "$FIX/password-encrypted.ofd" \
  --user fixture-password-user --password "$FIXTURE_PASSWORD" -o out # 加密转图→0
ofdrw-viewer-cli "$FIX/cert-encrypted.ofd" \
  --user fixture-cert-user --key "$FIX/certs/encrypt.key.pem" -o out # 私钥转图→0
ofdrw-viewer-cli decrypt "$FIX/plain.ofd"                            # 无 decrypt→1
```
