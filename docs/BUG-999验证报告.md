## 4. 四项修复的独立核验

### 4.1 CLI `--font-dir` 与 TTC/OTC 展开

- CLI 在 `convertDocument` 注入 `createNodeFontInputLoader()`；`path/filePath` 使用 `node:fs` 读取，`url` 使用 fetch；不改变 Web 默认 loader。
- 引擎 `FontLibrary` 对补充字体使用 `createFontFaces` 展开 TTC/OTC 全部字体面，并用 fontkit 真实 family 参与匹配；不再只取第 0 个面。
- 实测 `999.ofd` 的 5 页全部导出，`W_FONT_MISSING=0`；截图正文可读。
- 测试证据：
  - `packages/ofdrw-viewer-engine/test/api/compat-999.test.ts` 2/2（含 skipIf 字体目录；本机目录存在，未 skip）
  - `packages/ofdrw-viewer-engine/test/font/provider.test.ts` 25/25（path 来源经 loadInput 读取、实际 family）
  - `packages/ofdrw-viewer-cli/test/e2e/cli.test.ts` 的 999 `--font-dir` 用例通过
  - `packages/ofdrw-viewer-cli/test/unit/fonts.test.ts` loader path/filePath/错误语义
- 注意：真实字体目录为 `/mnt/c/Windows/Fonts`（697 个文件）；若在其他环境缺失，测试会条件 skip；本报告未把 skip 当通过，已实际执行并观察 `W_FONT_MISSING=0`。

### 4.2 `g 0` 空展开与非法值

- `src/xml/numbers.ts` 将 `count >= 0` 作为合法；`g 0 0 3.175` 产生 `[3.175]`，不回调。
- 负数、非整数、缺值、非数字仍回调 `W_BAD_NUMBER`。
- 999.ofd 中 17 处 `g 0 0 3.175`，修复后无 `g 压缩组格式非法`/`DeltaY` 告警。
- 测试：`test/xml/numbers.test.ts` 8/8，包含 `g 0` 合法与负数/小数/缺值非法两组断言；全量 engine 821 passed。

### 4.3 Page 面积回退 warning 语义

- 解码期 `decodePageContentNode`/`decodePageAreaXml` 不再为“缺失 Area/PhysicalBox”发 `W_BAD_NUMBER`；只有显式非正/原点异常仍告警。
- `getPage`/`getPageInfos` 均仅用有效页 Area 参与“页 → 模板 → CommonData → A4”回退；最终 A4 才由 `resolvePageArea` 统一告警一次。
- 实测 999.ofd（旧日志有 Page 缺少 Area）修复后无该告警；`test/api/document.test.ts` 20/20；`test/model/page-info.test.ts` 3/3。

### 4.4 空注释 Appearance 去重

- 模型解码阶段提示 1 次；`buildAnnotationBlocks` 渲染阶段静默跳过，不再重复。
- 999.ofd 摘要 `W_ANNOT_EMPTY×1`；`test/api/compat-999.test.ts`、`test/api/annotations.test.ts`、`test/render/annotation.test.ts` 均断言 1 条。

## 7. 条件与残余风险

1. **字体目录依赖**：本次 `/mnt/c/Windows/Fonts` 可用且实际执行；在其他 CI 环境无该目录时，999 字体用例按设计 skip，不能把 skip 当作通过。若发布门禁要求全环境字体测试，应提供可提交的合成字体 fixture 或固定字体包。
2. **剩余 W_BAD_NUMBER**：带字体后 6 条中 2 条 ColorSpace、4 条 DeltaX 数组长度不匹配。后者是样本真实非法输入，保留告警符合验收要求；如需为 999 做“warning 全清零”必须另立需求并修改样本/预期，不应在本修复中静默吞掉。
3. **`--font-dir` 性能**：697 个字体文件、5 页约 16.3s；这是全目录扫描/字体展开成本，不影响正确性；如生产 CLI 需常驻，可考虑字体缓存（另立任务，不阻断本 bug）。
4. **t97 公共类型**：本次只验证导入与文档同步；未改变 `loadInput` 运行时行为。Web 默认 loader 仍不支持 `path`，Node/CLI 才注入 loader；符合“Web 优先、Node 端适配不在本轮”的边界。
