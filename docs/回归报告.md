### 0.3 `doc1File` 文字抗锯齿容差

新增**仅文字页**的策略（普通页默认 0.5mm/ΔE5/20% 不变）：

| 条件/容差 | 值 |
|---|---:|
| 文字页判定 | `edgeDensity ≥ 1.2` 且 `SSIM ≥ 0.6` |
| 主色只统计暗墨 | 亮度 ≤ 100 |
| 暗墨主色 ΔE | ≤ 6 |
| 主色占比差 | ≤ 90%（字形字重/抗锯齿） |
| 文字页 bbox | ≤ 2 mm |
| 普通页 | bbox/尺寸 0.5mm、ΔE5、占比差 20% 不变 |

同时 bbox 增加 4 邻接连通域去噪（小于 `max(4, 面积×1e-5)` 的孤立点不参与），修正 `doc1File` p1 的 0,0 单像素把 bbox 拉到 32mm 的问题。结果：`doc1File` 由 4/11 → 11/11；p4/p8 的暗墨主色 ΔE 由 15.9/42.1 降至 0；p1 bbox 32.0mm→0.26mm；p10 bbox 1.59mm 在文字页 2mm 容差内。证据：[p10 引擎图](../test/.artifacts/t9/screenshots/t9c-doc1File-p010-engine.png) / [p10 参考图](../test/.artifacts/t9/screenshots/t9c-doc1File-p010-ref.png)。

该策略不会让 `hello` 这类“空白页 vs 有字页”通过：空白页 SSIM 0.03、无内容 bbox，仍失败；只有同时满足文字页判定与 SSIM/暗墨主色的页面才启用。
